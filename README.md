# Radio Inteligente — SARP.es

Descargas de **Radio Inteligente Dispatch LSPD** para Windows 10/11.
Cada ZIP contiene Dispatch portable, WAV, voces en español e inglés, el motor de voz y WebView2 local.
No hace falta instalar Python ni iniciar sesión en GitHub para usarla.

Las versiones de prueba se identifican como beta. No sustituyen una definitiva.
Consulta la guía y LEEME incluidos en cada paquete. Antes de actualizar mediante
un ZIP, cierra la radio desde **Salir** en la bandeja de iconos de Windows.

Este repositorio se dedica a la distribución; no contiene el proyecto de desarrollo.
Los catálogos de actualización están firmados. No se suben registros de jugadores.
Incidencias: mensaje por Discord a **elchimeneas**, indicando edición y versión.
